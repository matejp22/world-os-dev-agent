# GIT RULES

Primary branch:
main

Rules:
- Never use "git add ."
- Review git status before staging.
- Review git diff before commit.
- git add requires human approval.
- git commit requires human approval.
- git push requires human approval.

When Git push commands are eventually presented to the developer,
provide git add, git commit and git push together in one block.

Do not treat untracked files as disposable without inspection.
